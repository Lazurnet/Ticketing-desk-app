# Projet
Application interne de gestion des prestations et activités des prestataires.

L'objectif de l'application est de :

- Centraliser les informations des équipements.
- Associer des tâches techniques à réaliser.
- Tracer les PV produits par les prestataires.
- Permettre la validation des PV par les équipes Renault.
- Assurer la traçabilité des actions effectuées.


## Stack

- Fedora 44
- Python 3.14
- Django 6
- SQLite (V1)
- PostgreSQL (prévu)
- Bootstrap
- VS Code Remote SSH
- GCP
  
## Fonctionnalités V1
- Gestion des prestataires
- Gestion des prestations
- Gestion des superviseurs
- Dashboard
- Authentification
